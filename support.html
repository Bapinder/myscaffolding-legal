Getting started

Open the app and tap + New job. A job needs a client, a site and a date it goes up — everything else can wait. When the scaffold is up, set the date it went up, and the app takes over from there: it starts the hire clock and schedules the first inspection.

Sharing with your crew

Starting a shared tracker

Settings → Start a shared tracker. You get an eight-character code. Read it out to your lads or send it on.

Joining one

Settings → Join, then type the code. Case and spaces do not matter. From then on everything anyone changes reaches everybody.

Keep the code to your firm

Anyone holding the code can see and change the tracker. There are no passwords — the code is the key. If it gets out, start a fresh tracker and move over.

Inspections

A scaffold that goes up gets an inspection due seven days later, and your phone reminds you the morning it falls due. Tap Inspected today and the clock rolls forward another seven days. It stops by itself once the scaffold comes down.

You can change the interval, or switch reminders off altogether, in Settings.

Not getting reminders? Check the app is allowed to notify you: iPhone Settings → Notifications → My Scaffolding Ltd. On Android, Settings → Apps → My Scaffolding Ltd → Notifications.

Photos and location

Both are optional and only ever asked for at the moment you tap the button that needs them. The app works fully if you say no to either.

Photos are shrunk on the way in, so they cost very little room. If the app warns you it is filling up, export a backup from Settings and delete photos from old jobs that are long down.

Backups

Settings → Export backup writes a file you can send to yourself and keep. Import backup puts it back. Worth doing now and then, especially if you are working on one phone rather than a shared tracker.

Common questions

Does it work without a signal?

Yes. Everything except syncing a shared tracker works with no signal at all, including the site map. Changes catch up the next time you have one.

Can I use it on more than one phone?

Yes — that is what a shared tracker is for. Without one, each phone keeps its own separate copy.

Two of us saved at the same time. What happens?

Nothing is lost. The app merges job by job: whoever touched a particular job last keeps it, and jobs only one of you touched are all kept.

How do I delete everything?

Settings → Erase everything clears the phone. To have a shared tracker removed from our server as well, write to the address above.
